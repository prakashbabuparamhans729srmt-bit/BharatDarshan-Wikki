# **App Name**: BharatDarshan Wiki

## Core Features:

- Geographical Content Display: Browse rich textual and image-based content detailing Indian states, districts, and various points of interest, displayed via dynamic routes.
- Advanced Content Discovery: Utilize powerful search functionality and flexible filtering options, including categorical and alphabetical listings of states and districts, for efficient content navigation.
- Multi-User Content Contribution: Allow registered users to securely log in, create new articles about places, states, and districts, and edit existing content in a collaborative, Wikipedia-like environment.
- AI Multi-Language Content Tool: Provide a tool to translate content into multiple Indian languages using generative AI, making information accessible to a wider audience.
- AI Voice Search Tool: Integrate an AI-powered voice search tool enabling users to discover content hands-free, by simply speaking their queries.
- AI Content Refinement Tool: Assist contributors with an AI tool that provides suggestions for content improvement, summarization, and potentially fact-checking to enhance article quality.
- User Contribution Dashboard: A dedicated dashboard for authenticated contributors to view and manage their submitted content, track editing history, and update their personal profile.

## Style Guidelines:

- The overall theme is light, offering clarity and comfort for extensive reading. The primary color, #BA4222 (RGB: 186, 66, 34), is a warm, muted saffron-terracotta, selected to evoke India's rich heritage and grounded wisdom. It is versatile enough for interactive elements and prominent branding without overwhelming the content.
- The background color, #F9F1EE (RGB: 249, 241, 238), is a soft, warm off-white. This choice creates a spacious and inviting canvas that minimizes eye strain, ideal for a content-heavy application, while maintaining a subtle relationship with the primary hue.
- The accent color, #E0325E (RGB: 224, 50, 94), is a vibrant magenta-red. This analogous hue provides strong visual contrast, making calls-to-action, alerts, and critical highlights immediately noticeable without disrupting the platform's informative character.
- Headlines will utilize 'Alegreya' (serif), an elegant and intellectual font that provides a distinct character and sophisticated touch to article titles. Body text will use 'Inter' (sans-serif), chosen for its modern, objective, and highly legible design, ensuring a comfortable reading experience across all devices.
- Adopt a clean, minimalist set of line icons. Icons should clearly represent their function (e.g., search, edit, translate, navigate) and be easily understood by a diverse user base, maintaining consistency with a global knowledge platform.
- Implement a responsive, adaptive grid layout that ensures optimal content presentation and readability on any screen size. Key elements include a fixed header, and a custom hidden side navigation panel that can be toggled to maximize content viewing area.
- Incorporate subtle and functional animations for user feedback, such as smooth transitions for content loading, page changes, and menu expansions/contractions, enhancing the user experience without causing distraction.
